# Demand Planning Dashboard

Interactive demand planning dashboard: moving-average forecast with seasonality, forecast accuracy (MAPE, bias), safety stock, reorder points, fulfillment rate, and a promotion scenario. Upload your own Excel data on the Settings & data page.

All sample data is fictional.

## Version 2

A second version is in [`/v2/`](v2/): three product categories, 3 years of history, three forecast models with automatic selection (moving average + seasonality, Holt-Winters, seasonal naive), MAPE, WMAPE, bias, MAD and forecast value added, exceptions, a consensus planning view (statistical forecast → Global Demand Plan → Consensus Demand Plan → business plan), inventory and an S&OP management summary. The original version stays at the main link.
